M3-3 – ANALYSIS AT SYNTHETIC SLIDING EVENT
Source: Giai_doan_1_Synthetic_Dataset_6_kich_ban.csv.
Primary event label: event_label (M5-B state machine label).
Event time is the first minute in each scenario where event_label == SLIDING.
Windows:
PRE_20MIN=[t0-20,t0-1], PRE_10MIN=[t0-10,t0-1], PRE_5MIN=[t0-5,t0-1],
EVENT_MINUTE=[t0,t0], POST_5MIN=[t0,t0+4], POST_10MIN=[t0,t0+9], POST_20MIN=[t0,t0+19].
Same-clock comparison samples each scenario at the event scenario's event minute.
Only synthetic labels are analyzed. SLIDING is M5-B rule-generated, not an observed physical slide.
If only one scenario has SLIDING, results describe that scenario and cannot establish generalizable slide thresholds.
C2 features are generated by the pressure-coupled hypothesis branch; their behavior is structurally dependent on pressure.
M4-A1/A2 reference features are not pressure-coupled.
All values and event windows are exploratory synthetic-model outputs, not experimental ground truth.
